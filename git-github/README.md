# Git/GitHub

## Introduction

Git and GitHub are technologies every developer nowadays need to understand how it works,
and specially how to use it.

A quick definition of Git and GitHub before diving deep into it:

- **Git** Is a software made to solve the universal issue of versioning other
software projects.
Its specialized in tracking changes made in the past with the intention of reviewing who,
when, where, and what changed.

- **GitHub** Is a Git repository manager. It handles repositories remotely
(more on this later). GitHub makes easier sharing projects and working with other people
